# Personal Coaching Website

## Overview
Personal development coaching website designed and built entirely 
from scratch using WordPress. Focused on minimalist design, clear 
messaging and conversion-oriented structure.

## Features
- Clean, minimalist design
- Service presentation and positioning
- Contact and application form
- Mobile responsive
- Spanish language — targeting Latin American market

## Tech Stack
- WordPress
- Custom CSS
